# Ruminate

`/reflect` ดูแค่ session ปัจจุบัน. Ruminate ย้อนดู **ทุก session ที่ยังเก็บอยู่** เพื่อหาสิ่งที่หลุดไป.
Claude Code เก็บ transcript 365 วัน (`cleanupPeriodDays` ใน `~/.claude/settings.json`) — ถ้าค่านี้หาย ประวัติจะถูกลบทุก 30 วัน.

## 1. Extract (ห้ามอ่าน .jsonl ดิบ — 90% เป็น tool output)

```bash
python3 -I .claude/skills/ruminate/scripts/extract_conversations.py \
  ~/.claude/projects/-Users-alonsi-Desktop-studio <scratchpad>/rumi \
  --from <วันที่รอบก่อน จาก .last_run> --skip <session id ปัจจุบัน>
```
ได้ไฟล์ละ 1 session: ข้อความผู้ใช้เต็ม + ข้อความ assistant ตัดเหลือ 600 ตัวอักษร.

## 2. อ่าน memory ที่มีอยู่ก่อน
อ่าน `MEMORY.md` (index) + `CLAUDE.md` + `guides/guardrails.md` + `guides/principles.md` — อะไรที่บันทึกไว้แล้ว **ข้าม**.

## 3. วิเคราะห์
- ≤5 session → อ่านเองทั้งหมด
- >5 session → แบ่ง batch ละ ~5 ไฟล์ ส่ง subagent `model: sonnet` (ไม่ใช่ opus) อ่านพร้อมกัน แต่ละตัวคืนผลตามหัวข้อด้านล่าง

หา:
| หัวข้อ | ตัวอย่างสัญญาณ |
|---|---|
| ผู้ใช้แก้/ค้าน | "ไม่ใช่", "ผิด", "บอกแล้วว่า", สั่งให้ทำใหม่ |
| สั่งซ้ำ | ความต้องการเดิมที่พูดมากกว่า 1 session |
| ปัญหาวนกลับ | error/workaround เดิมโผล่ซ้ำ (login หมด, tool พัง, path ผิด) |
| เสีย usage ฟรี | วนลูปรอ/poll, ทำซ้ำหลายรอบเพราะไม่คิดก่อน, rebuild ทั้งที่มีของเดิม |
| อยากได้เครื่องมือ | "ทำให้อัตโนมัติได้ไหม", "ทุกครั้งต้อง…" |

## 4. กรองหนัก
เก็บเฉพาะ: **เกิดซ้ำ** (≥2 session หรือแก้เรื่องเดิมซ้ำ) **หรือ** ผลกระทบสูง (เสียเวลา/usage มาก, ข้อมูลผิด) **หรือ** memory เดิมผิดแล้ว.
3 ข้อที่ชัด ดีกว่า 10 ข้อที่ปนขยะ. บอกตรงๆ ว่าข้อไหนเกิดครั้งเดียว.

## 5. เสนอผู้ใช้ — ห้ามแก้เองก่อนได้รับอนุมัติ
ตาราง: **สิ่งที่เจอ | หลักฐาน (session/วันที่, กี่ครั้ง) | เสนอให้ทำ**
"เสนอให้ทำ" ต้องเลือกปลายทางตาม `guides/principles.md` §1 — ฝังเป็นโครงสร้างก่อน (แก้ skill/agent/สคริปต์/hook), memory เป็นทางเลือกสุดท้าย.

## 6. หลังผู้ใช้อนุมัติ
ทำตามที่เลือก แล้วเขียนวันที่วันนี้ลง `.claude/skills/ruminate/.last_run`.
